API 端点文档

用户认证 API

POST /api/auth/register - 用户注册
请求体: {"username": "string", "password": "string", "email": "string", "display_name": "string"}
POST /api/auth/login - 用户登录
请求体: {"username": "string", "password": "string"}
GET /api/auth/me - 获取当前用户信息
请求头: Authorization: Bearer {session_token}
PUT /api/auth/profile - 更新用户资料
请求头: Authorization: Bearer {session_token}
请求体: {"display_name": "string", "email": "string"}
POST /api/auth/change-password - 修改密码
请求头: Authorization: Bearer {session_token}
请求体: {"old_password": "string", "new_password": "string"}
POST /api/auth/refresh - 刷新会话令牌
请求头: Authorization: Bearer {session_token}
请求体: {"refresh_token": "string"}
POST /api/auth/logout - 用户登出
请求头: Authorization: Bearer {session_token}

模板管理 API

POST /api/templates - 创建模板
请求头: Authorization: Bearer {session_token}
请求体: {"name": "string", "workflow_data": "string", "description": "string", "category": "string", "tags": "string", "is_public": boolean}
GET /api/templates - 获取模板列表
请求头: Authorization: Bearer {session_token}
查询参数: include_public, page, page_size, sort_by, sort_order, category, search
GET /api/templates/{id} - 获取模板详情
请求头: Authorization: Bearer {session_token}
PUT /api/templates/{id} - 更新模板
请求头: Authorization: Bearer {session_token}
请求体: {"name": "string", "description": "string", "category": "string", "tags": "string", "is_public": boolean}
DELETE /api/templates/{id} - 删除模板
请求头: Authorization: Bearer {session_token}
POST /api/templates/{id}/favorite - 切换收藏状态
请求头: Authorization: Bearer {session_token}
POST /api/templates/{id}/use - 使用模板（增加使用次数）
请求头: Authorization: Bearer {session_token}
GET /api/templates/categories - 获取分类列表
请求头: Authorization: Bearer {session_token}
查询参数: include_public
GET /api/templates/popular - 获取热门模板
查询参数: limit, days
